# PatternMatch

PatternMatch is a mobile memory game built with React Native and Expo. Players flip cards to find matching pairs and complete the board using as few moves as possible.

## Features

- Card-matching memory game
- Move tracking
- Game completion and restart functionality
- Responsive mobile UI
- Available on the Apple App Store

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- iOS

## Getting Started

### Prerequisites

- Node.js
- npm
- Expo
- Xcode (for iOS development)
